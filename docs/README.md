Below is the directory map of all technical specification documents available in this folder:

1. 📄 **[PROGRESS.md](file:///d:/projects/mq-webifylab-posky/docs/PROGRESS.md)**
   - Tracking linimasa, status milestone pengembangan, dan daftar tugas yang sudah/sedang diselesaikan.

5. 🎨 **[DESIGN.md](file:///d:/projects/mq-webifylab-posky/docs/DESIGN.md)**
   - Spesifikasi sistem desain UI/UX, token warna, tipografi, komponen kasir, dan standar responsivitas Next.js.
6. 📐 **[BLUEPRINT.md](file:///d:/projects/mq-webifylab-posky/docs/BLUEPRINT.md)**
   - Cetak biru model bisnis hybrid (Barang, Jasa, Sewa) dan formulasi matematis DSS AHP & Facebook Prophet Forecasting.
7. 📜 **[adr/](file:///d:/projects/mq-webifylab-posky/docs/adr)**
   - *Architecture Decision Records* (ADR) — Catatan keputusan arsitektural penting yang diambil selama pengembangan.
